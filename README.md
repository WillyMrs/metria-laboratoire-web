# MÉTRIA — laboratoire Web de test

Prototype autonome du laboratoire Web MÉTRIA V16. Il permet de créer plusieurs pièces, de renseigner leurs murs et de consulter un plan coté généré automatiquement. Les supports du calcul matière sont choisis parmi ceux déclarés compatibles avec le produit.

Les outils de dessin libre et d’élévation ont été retirés. Ce dépôt ne contient pas les sources natives iOS.

Les essais sont enregistrés uniquement dans le stockage local du navigateur et ne sont pas synchronisés entre appareils. N’y saisir aucune donnée réelle de client.
