# MÉTRIA — laboratoire Web de test

Prototype autonome du laboratoire Web MÉTRIA V17. Il permet de créer plusieurs pièces, de renseigner leurs murs et de consulter un plan coté généré automatiquement. Les supports du calcul matière sont choisis parmi ceux déclarés compatibles avec le produit. À la sélection d’un produit, les données techniques, conditionnements et tarifs connus sont préremplis.

Les outils de dessin libre et d’élévation ont été retirés. Ce dépôt ne contient pas les sources natives iOS.


Les tarifs par conditionnement restent partiels : seuls les montants sourcés sont préremplis et les cellules inconnues restent vides. Pour certains enduits, l’épaisseur préremplie est le maximum conseillé par passe dans la fiche technique ; elle est indicative et doit être ajustée à l’épaisseur moyenne réelle du chantier. Lorsqu’aucune valeur fiable n’est publiée, le champ reste à renseigner. Le rendement des références EVALUX 12 L n’est pas renseigné faute de fiche technique attribuable à ces produits.

Les essais sont enregistrés uniquement dans le stockage local du navigateur et ne sont pas synchronisés entre appareils. N’y saisir aucune donnée réelle de client.
